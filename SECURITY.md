# Security & Clinical Safety Policy

## 🛡️ Supported Versions

We provide security and clinical accuracy patches for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 2.x.x   | :white_check_mark: |
| < 2.0   | :x:                |

---

## 🔒 Reporting a Vulnerability

If you discover a security vulnerability or critical medical misinformation within Body Explorer, please do **NOT** open a public issue.

Instead, please submit your finding responsibly:

1. Email details to the repository maintainers with subject `[SECURITY] Body Explorer Vulnerability`.
2. Include reproduction steps, potential impact, and suggested remediations.
3. Allow up to 48 hours for an acknowledgment and assessment.

---

## 🩺 Reporting Clinical Inaccuracies

If you identify an outdated medical reference, incorrect physiological claim, or dangerous advice:

1. Open a GitHub Issue tagged `clinical-review` or submit a direct pull request referencing the gold-standard source (WHO, CDC, PubMed PMID).
2. Clearly cite the replacement source and why the current content requires revision.
3. Issues marked `clinical-review` are prioritized with urgent triage.
